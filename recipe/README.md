# Babe's Honey Recipe Adapter

Paste a recipe (or upload a photo) and convert sugar → Babe's honey using locked baking-science rules.

- **Paste / photo OCR:** works in the browser (Tesseract for photos)
- **Link fetch:** only works in environments that expose `window.claude.complete`
- **Find Stores:** opens the live [store locator](https://apicvir.github.io/babes-store-locator/) filtered to the recommended honey SKU

Demo: `/recipe/` on the babes-store-locator GitHub Pages site.
